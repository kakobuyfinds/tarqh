Four checks from listing to parcel

Save the evidence you’ll need to compare the listing with what arrives at the warehouse.

01. LoongBuy product links

When a spreadsheet entry points to a Weidian listing, a Taobao product page or a 1688 seller page, record the original marketplace URL and seller name. Match the model or style code, then check the color option, size availability and SKU selection on the live listing. If two rows resolve to the same seller and item ID, count them as one listing.

02. LoongBuy size guide

For sneakers, compare the seller’s shoe size chart and insole length with a pair that fits. A size conversion chart helps interpret labels, while a measurement gives you something to compare directly. For hoodies and T-shirts, compare flat chest width, shoulder width and body length. For jackets, add sleeve length and allow room for a layer. For pants, check the laid-flat waistband, rise and inseam. For caps, check the head circumference range.

03. LoongBuy QC photos

Start with the warehouse overview photo, then match the size label and color to your order. On a shoe, look at heel alignment and outsole condition. On a jacket, inspect seam stitching and zipper alignment. For jewelry, ask for a clasp close-up. If fit matters, request a ruler photo with both ends of the measurement visible. Keep the photos and check the seller’s return window while the item is still at the warehouse.

04. LoongBuy shipping guide

Separate domestic delivery from the international freight quote. Compare shipping lines using actual weight and packed parcel dimensions, since a carrier may bill by volumetric weight. Before parcel consolidation, ask how shoe box removal might affect size and protection. Check tracking, coverage and any applicable import charges for the destination before dispatch.

Frequently asked questions

What is a LoongBuy spreadsheet?

A LoongBuy spreadsheet is a product discovery list that collects marketplace links and may include photos or notes. Open the source listing to check the seller, selected variant and current availability.

What should I do if a product link is broken?

Search again using the model name, style code or seller name. Before using a replacement link, confirm that the listing offers the same model, color and size.

Can warehouse QC photos establish authenticity?

Warehouse QC photos can show visible details such as labels, seams and marks. Authenticity requires separate evidence, such as verifiable provenance or an independent authentication service.

How can I estimate the total parcel cost?

Add the item subtotal, domestic delivery, international freight and any applicable fees or import charges. For a better freight estimate, compare quotes using the packed dimensions and weight.

Where do the category links go?

The category links open the corresponding CAfans catalog sections. The brand images on this page are visual references.
